# Contributing

NextCoder is currently maintained as a private project.

- For bug reports, questions, or design discussions, open an issue or contact
  [@POZLOIZ](https://github.com/POZLOIZ).
- Please open an issue before sending a pull request so the scope and approach
  can be agreed on first.
- Keep changes focused, follow the existing module boundaries, and run
  `uv run ruff check` plus `uv run pytest -q` before submitting.
