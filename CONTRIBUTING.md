# Contributing

NextCoder is currently maintained as a private project.

- For bug reports, questions, or design discussions, open an issue or contact
  [@POZLOIZ](https://github.com/POZLOIZ).
- Code changes are by invitation only; please open an issue first so the scope
  and licensing can be agreed on.
- If you have been invited to contribute, keep changes focused, follow the
  existing module boundaries, and run `uv run ruff check` plus
  `uv run pytest -q` before submitting.
